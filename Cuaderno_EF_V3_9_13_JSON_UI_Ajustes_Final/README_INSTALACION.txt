CUADERNO EF · INSTALACIÓN RÁPIDA

IMPORTANTE
Una PWA necesita abrirse desde una dirección HTTPS para poder instalarse correctamente en móvil/tablet. Abrir index.html directamente como archivo permite verla, pero no activa la instalación/offline completa.

OPCIÓN RECOMENDADA: GitHub Pages
1. Crea una cuenta gratuita en github.com si no tienes.
2. Crea un repositorio nuevo, por ejemplo: cuaderno-ef.
3. Sube TODOS los archivos de esta carpeta manteniendo la carpeta icons.
4. En el repositorio: Settings > Pages.
5. En Build and deployment selecciona "Deploy from a branch".
6. Branch: main / root. Guarda.
7. GitHub mostrará una dirección https://...github.io/cuaderno-ef/
8. Abre esa dirección en tu tablet y móvil.

ANDROID (Chrome)
- Abre la dirección HTTPS.
- Pulsa el botón "Instalar" de la app si aparece, o menú ⋮ > Añadir a pantalla de inicio / Instalar aplicación.

IPHONE/IPAD (Safari)
- Abre la dirección HTTPS en Safari.
- Compartir > Añadir a pantalla de inicio.

DATOS Y PRIVACIDAD
- Esta versión guarda los datos en localStorage del navegador del dispositivo.
- No sube nombres ni calificaciones a ningún servidor.
- Si borras los datos del navegador puedes perderlos: usa Ajustes > Exportar copia JSON con frecuencia.
- La sincronización entre dispositivos NO está incluida aún. Para eso habrá que añadir una base de datos y autenticación.

PRIMER USO
1. Ajustes > crea el grupo.
2. Pega los nombres, uno por línea.
3. Selecciona UP.
4. Evaluar > evidencia ● > toca la nota de cada alumno.
5. ○ > registra En proceso / Adecuado / Consolidado solo cuando aporte información útil.
6. Resumen > consulta cobertura, CE y nota.
